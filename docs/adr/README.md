# ADRs — Architecture Decision Records

Une ADR enregistre une décision structurelle, difficile à renverser, avec son contexte et ses conséquences.

## Format

Fichier `NNNN-titre-en-kebab.md` (numéro séquentiel, zéro-paddé) :

```markdown
# ADR-NNNN: Titre court

Date: YYYY-MM-DD
Statut: accepté | proposé | déprécié | remplacé par ADR-XXXX

## Contexte
Pourquoi la décision était nécessaire.

## Décision
Ce qui a été décidé.

## Conséquences
Ce que cela verrouille / rend plus facile, et les alternatives écartées.
```
